# 125A Bass Finisher V1

Authoritative Final repository for **125A Bass Finisher V1**.

Current release: **v1.0.0**
Platform: **Windows x64**
Format: **VST3**

Core signal flow:

`TONE MATCH -> FINISH -> MIX FIT -> OUT`

The release includes:
- reference/target Tone Match with saved profiles;
- adaptive bass-focused FINISH processing;
- CLEAN / PUNCH / DENSE processing profiles;
- LOW CONTROL for low-end placement and sub containment;
- MASS for weight / cleanup;
- final output trim;
- 100% / 150% GUI zoom.
